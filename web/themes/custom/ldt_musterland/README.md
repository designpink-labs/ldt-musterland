# Theme „LDT Musterland“

Theme der Musterseite *Landesamt für Digitale Teilhabe Musterland*, erzeugt mit dem
Drupal-Starterkit (`vendor/bin/dr generate-theme`). Reines CSS mit Custom Properties,
kein Build-Schritt. Ziel: WCAG 2.1 AA.

- Farben und Kontrastwerte: `css/base/tokens.css`, Übersicht unter `/styleguide`
- Eigene Komponenten: `css/components/ldt-*.css`, Druck: `css/print.css`
- Navigation (Disclosure-Muster): `js/navigation.js`, `templates/navigation/menu--main.html.twig`
- Icons (eigene, `aria-hidden`): `templates/icons/`
- Schrift: Atkinson Hyperlegible, `fonts/` (SIL Open Font License, `fonts/OFL.txt`)

Weitere Hinweise und die Prüfskripte stehen in der README im Projektordner.
